## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Подготовить Dockerfile API/worker и Compose: proxy со статикой Vite, PostgreSQL, Redis, worker, внутренний конвертер, persistent volumes, отдельные dev/test/prod конфиги. Оценить 4/8 ГБ по memory budget. Добавить env.example без ключей, fail-fast production validation и health/readiness. Все БД/Redis/render ports внутренние. Развёртывание за деньги или выбор конкретного аккаунта — отдельное действие владельца.

## Результат и приёмка

Одна документированная команда запускает стенд; рестарт сохраняет БД/файлы; TLS/proxy конфиг и firewall checklist конкретны; production с default secret/mock provider отказывается стартовать.

## Проверка

Compose config, health smoke, restart, внешний port scan на тестовом стенде; замер RAM idle.

## Область изменений

infra/, Dockerfiles, app/core/config.py, runbook; не внедрять Kubernetes.
