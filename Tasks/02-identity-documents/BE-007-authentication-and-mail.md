> Прежний расширенный план. Для первой версии этот файл не выполнять: использовать [новый реестр MVP](../README.md) и [summary.md](../../docs/backend/summary.md). Полезные проверки можно переиспользовать в пределах новых заданий; полный объём и прежние зависимости больше не обязательны.


Статус: SUPERSEDED для первого MVP. Приоритет: P0. Зависимости: BE-004, BE-005, BE-003.

## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Реализовать opaque cookie sessions, logout/revoke, Argon2id и миграцию bcrypt без нового молчаливого truncation. Email verification/reset одноразовыми hash tokens, TTL, нейтральные ответы, CSRF/Origin, rate limits. Подключить mail adapter с test sink, SPF/DKIM/DMARC runbook и минимальными данными. Trial только после verify/invite. Согласия сохранять по версии документа; не требовать маркетинг для регистрации.

## Результат и приёмка

Регистрация→письмо→verify→вход→выход/reset проходит; сессия отзывается; конкурентное использование reset token успешно один раз; secrets и tokens не попадают в логи.

## Проверка

Session fixation, CSRF, expired/reused token, parallel reset, bcrypt migration, password Unicode/length, enumeration/rate-limit tests.

## Область изменений

app/core/security, auth endpoints/models, mail service; UI подключается в BE-016.
