Статус: SUPERSEDED для первого MVP. Приоритет: P1. Зависимости: BE-005, BE-007.

## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Разделить создание черновика и генерацию. CRUD owner scoped, cursor pagination без AST в списках, immutable versions, revision/If-Match. Сохранение исходных параметров, отдельных outline versions и approval snapshot. Добавить безопасный прогресс GET jobs и отключить текущие публичные WS/SSE до полноценной auth. Все job/download endpoints используют единые проверки доступа.

## Результат и приёмка

Пользователь продолжает работу с другого устройства; чужие ID не раскрывают данные; конфликт версий возвращает 409; approved plan не меняется внутри запущенной генерации.

## Проверка

User A/B matrix для CRUD/progress/streams/files; pagination; parallel edits; draft без списания.

## Область изменений

app/api/documents, schemas, document services; не выполнять LLM в CRUD запросе.
