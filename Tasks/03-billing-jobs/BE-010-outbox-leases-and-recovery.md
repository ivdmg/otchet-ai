## Объём

В одной transaction сохранить reserve+job+input snapshot+outbox. Dispatcher доставляет Celery с повторами; worker идемпотентно acquires lease/fencing token. Watchdog восстанавливает зависшие операции, хранит heartbeat/attempts/backoff. Не удерживать SQL locks во внешних HTTP. Уникальность active writer per document. Cancel/retry сохраняют историю и не создают повторный charge.

## Результат и приёмка

Commit без публикации автоматически доставляется позже; duplicate delivery/старый worker не портят данные; терминальная ошибка освобождает резерв ровно один раз.

## Проверка

Kill после commit, до/после publish, после LLM до checkpoint; Redis restart, duplicate tasks, expired lease, competing resume, terminal compensation.

## Область изменений

app/tasks/core celery, jobs/outbox services; state сохраняется в PostgreSQL.
