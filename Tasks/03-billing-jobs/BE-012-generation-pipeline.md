## Контекст

## Объём

Перестроить pipeline на сохранённые step/node IDs и immutable approved outline. Сохранять каждый успешный раздел, а не считать готовые главы по количеству. Не регенерировать outline при resume. Добавить валидацию AST/ограничения объёма, источники/provenance и безопасные ошибки. Spot regeneration через тот же job механизм с base revision и резервом; не перезаписывать готовую версию.

## Результат и приёмка

Resume сохраняет ранее завершённые разделы и тот же план; spot создаёт новую версию; бюджет и progress соответствуют реальным шагам; generated text не означает ready files.

## Проверка

Interrupted pipeline, invalid JSON repair, changed plan rejected, source validation, concurrent spot/edit, terminal fail compensation.

## Область изменений

app/services/llm/*, tasks/generation.py, checkpoint service; DOCX handlers сохранять.
