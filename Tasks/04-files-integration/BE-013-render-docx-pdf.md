## Объём

Подключить render queue: AST version→python-docx→LibreOffice/Gotenberg→S3; ограничить slots/memory/timeouts/tmp и запретить внешнюю сеть/ссылки. Закрепить версии renderer/fonts и лицензионное основание шрифтов. Cache по hash/version. Проверить 10/30/60 страниц, таблицы, формулы, сноски, кириллицу и Word. Ready только после обязательных файлов, затем capture через идемпотентную операцию.

## Результат и приёмка

Повторное скачивание не запускает LLM/render; PDF/DOCX одного текста и версии; failure render не списывает окончательно; worker OOM не валит API; font decision задокументирован.

## Проверка

Visual golden fixtures + PDF text/page checks, damaged DOCX, timeout, network/file URI denied, S3 partial upload, measured RAM peak.

## Область изменений

app/docx_engine, render workers/storage; UI print export не использовать как production PDF.
