# BE-014. Безопасная обработка методичек

> Прежний расширенный план. Для первой версии этот файл не выполнять: использовать [новый реестр MVP](../README.md) и [summary.md](../../docs/backend/summary.md). Полезные проверки можно переиспользовать в пределах новых заданий; полный объём и прежние зависимости больше не обязательны.


Статус: SUPERSEDED для первого MVP. Приоритет: P1. Зависимости: BE-006, BE-007, BE-010.

## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Реализовать upload quota/type/magic/size checks, private quarantine и изолированное извлечение текста/требований. DOCX zip bounds/path traversal; PDF limits; запрет макросов/внешних ссылок; очистка ПД перед LLM и retention. Без готового безопасного pipeline скрыть upload в UI, не имитировать обработку выбранного файла.

## Результат и приёмка

Файл другого пользователя недоступен; неподдерживаемые/опасные файлы отклонены до LLM; удаление выполняется по сроку; status scan/parse понятен пользователю.

## Проверка

Oversize, zip bomb fixture без опасного распаковывания, zip-slip, MIME mismatch, foreign owner, parser timeout and network isolation.

## Область изменений

upload endpoints/parser workers, input requirements schema; не добавлять OCR/vector DB без отдельной потребности.

## Передача результата

Обновить статус в [реестре](../README.md), описать миграции/конфиги и выполненные проверки с результатами. Если внешних реквизитов/договоров нет, отделить готовый код и sandbox от блокируемого боевого запуска. Не отмечать DONE по одному наличию файлов или mock-тестов. Не менять визуальный дизайн без необходимости задачи; не делать deploy/покупку/боевой платёж автоматически.
