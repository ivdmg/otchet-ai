Интегрировать API в src/redesign/Studio.tsx, который экспортируется App. Убрать demo user/balance, localStorage как хранилище работ, timer progress, local buildChapters как реальную генерацию и client export как реальные файлы. Ввести loading/error/empty/auth states, draft autosave revision, recovery, refresh session, queued/failed/retry и backend order status. Demo сохранить только явно обозначенным режимом. Визуал не переделывать.

## Результат и приёмка

Два браузерных сеанса видят одну библиотеку; reload не теряет job; баланс нельзя увеличить из UI; скачивается серверная версия; отсутствие API показывает ошибку, не фиктивный успех.

## Проверка
