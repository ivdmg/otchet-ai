# BE-017. Претензии, возвраты и кабинет оператора

Статус: SUPERSEDED для первого MVP. Приоритет: P0. Зависимости: BE-003, BE-009, BE-015.

## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Добавить owner refund request, operator MFA/permissions/audit, partial refund calculation по lots и доступному/потреблённому объёму. Reserve спорных credits, provider refund idempotency, статус reconciliation и соответствующий налоговый чек. Шаблоны ответа без безусловного отказа по скачиванию. Сроки обработки/уведомления по утверждённой политике.

## Результат и приёмка

Refund не превышает оплату; спорный остаток не может параллельно тратиться; failed/pending refund не считается confirmed; банковская и внутренняя история сходятся.

## Проверка

Concurrent refund/spend, partial/multiple refunds, repeated webhook, timeout create refund, receipt correction failure, unauthorized operator.

## Область изменений

refund service/API, minimal admin controls, support runbook; не собирать номера карт.
