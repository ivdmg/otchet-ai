## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Настроить offsite encrypted DB backups и проверку файлов, restore drill в чистое окружение. Развести beta RPO24h и paid target RPO15m: при выборе последнего WAL/PITR или эквивалент, не ежедневный dump. Метрики queue age/memory/LLM cost/payment/receipt/backup, action alerts. Нагрузочный сценарий 20 RPS CRUD + burst jobs, render fixtures; подобрать concurrency и VPS по результату.

## Результат и приёмка

Есть отчёт restore с временем/потерей данных, реальные p50/p95/RAM и предел очереди, подтверждённый бюджет инфраструктуры; алерты проверены; платный RPO принят владельцем.

## Проверка

Restore from scratch, disk-full simulation in isolated environment, Redis restart, burst generation stub vs real bounded LLM benchmark.

## Область изменений

infra/monitoring/backup scripts and runbook; не проводить разрушительные эксперименты на пользовательской БД.
