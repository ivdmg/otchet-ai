Статус: SUPERSEDED для первого MVP. Приоритет: P0. Зависимости: BE-014, BE-016, BE-017, BE-018, BE-019.

## Контекст

Прочитать [обзор архитектуры](../../docs/backend/README.md) и связанные спецификации. Это отдельное задание для последующего агента, не отчёт об уже выполненной реализации.

## Объём

Собрать traceability matrix всех P0 и приёмок. Проверить owner/auth/streams/CSRF, dependency scan, secrets, S3 ACL, sandbox egress, adversarial webhook, финансовые гонки и kill-worker tests на PostgreSQL. Разделить beta gate и paid gate с юридическими подтверждениями, кассой/возвратами и restore. Закрыть несоответствия до допуска, а не только описать их.

## Результат и приёмка

Нет открытых P0; каждый gate имеет доказательства и владельца решения; sandbox E2E и runbooks воспроизводимы; никаких боевых секретов в fixtures; production deploy не выполняется этим ревью автоматически.

## Проверка

Security regression suite + полный критический E2E; отчёт ограничений, unresolved findings с приоритетом.

## Область изменений

tests/security/integration, release checklist and docs; новые product features не добавлять.

## Передача результата

Обновить статус в [реестре](../README.md), описать миграции/конфиги и выполненные проверки с результатами. Если внешних реквизитов/договоров нет, отделить готовый код и sandbox от блокируемого боевого запуска. Не отмечать DONE по одному наличию файлов или mock-тестов. Не менять визуальный дизайн без необходимости задачи; не делать deploy/покупку/боевой платёж автоматически.
