Сценарий: лендинг→форма с ценой→регистрация/вход без потери формы→настоящий AI-план→ручная правка/утверждение→выбор «Оплатить X ₽» или «Использовать X кредитов»→платёж test ЮKassa либо bonus reserve→настоящий прогресс→DOCX→библиотека. Cookie-auth/CSRF и polling делать по фактическому контракту, с паузой/backoff на ошибки и отменой запросов при уходе со страницы.

Progress UI показывает сохранённые шаги/раздел X из N. Процент не растёт при зависшем LLM; отдельные queue/checking-payment/retry/formatting состояния. 100% только когда backend подтвердил файл. На неопределённой оплате не предлагай платить повторно вслепую. Покажи номер заказа и способ поддержки.
