# ГОСТ Спецификация Форматирования DOCX Компилятора

Настоящий документ содержит исчерпывающий набор математических и точных технических параметров для настройки стилей Word в `python-docx` компиляторе. Соблюдение этих правил гарантирует 100% соответствие требованиям ГОСТ 7.32-2017, ГОСТ 2.105-95 и ГОСТ Р 7.0.100-2018.

---

## 1. Настройки Страницы (Page Setup & Margins)

* **Формат бумаги:** A4 ($210 \times 297$ мм).
* **Ориентация:** Книжная (Portrait).
* **Поля (Margins):**
  * **Левое (Left):** $30\text{ мм}$ ($3.0\text{ см}$ / `Mm(30)`).
  * **Правое (Right):** $10\text{ мм}$ ($1.0\text{ см}$ / `Mm(10)`) или $15\text{ мм}$ ($1.5\text{ см}$) — значение по умолчанию $10\text{ мм}$.
  * **Верхнее (Top):** $20\text{ мм}$ ($2.0\text{ см}$ / `Mm(20)`).
  * **Нижнее (Bottom):** $20\text{ мм}$ ($2.0\text{ см}$ / `Mm(20)`).

### Код настройки параметров страницы в python-docx:
```python
from docx.shared import Mm

section = doc.sections[0]
section.page_width = Mm(210)
section.page_height = Mm(297)
section.left_margin = Mm(30)
section.right_margin = Mm(10)
section.top_margin = Mm(20)
section.bottom_margin = Mm(20)
```

## 2. Основной Текст (Body Text Style)

* **Гарнитура (Font Family):** Times New Roman.
* **Кегль (Font Size):** $14\text{ pt}$ (`Pt(14)`).
* **Цвет шрифта:** Черный (`RGBColor(0, 0, 0)`).
* **Начертание:** Обычный (Regular).
* **Выравнивание (Alignment):** По ширине (Justified / `WD_ALIGN_PARAGRAPH.JUSTIFY`).
* **Межстрочный интервал (Line Spacing):** Полуторный ($1.5$ / `line_spacing = 1.5`).
* **Абзацный отступ (Красная строка / First Line Indent):** $1.25\text{ см}$ ($709\text{ dxa}$ в OpenXML / `Cm(1.25)`).
* **Отступы До и После абзаца (Space Before / After):** $0\text{ pt}$ (`Pt(0)`).
* **Перенос слов:** Автоматическая расстановка переносов (Hyphenation enabled).

## 3. Заголовки (Headings & Structure)

### 3.1. Заголовки 1-го уровня (Главы, Введение, Заключение, Список литературы)
* **Размещение:** Начинаются **С НОВОЙ СТРАНИЦЫ** (`paragraph_format.page_break_before = True`).
* **Гарнитура:** Times New Roman.
* **Кегль:** $14\text{ pt}$ (или $16\text{ pt}$ полужирный).
* **Начертание:** Полужирный (Bold), ПРОПИСНЫЕ БУКВЫ (ALL CAPS).
* **Выравнивание:** По центру (Center / `WD_ALIGN_PARAGRAPH.CENTER`).
* **Абзацный отступ:** $0\text{ см}$ (без красной строки / `first_line_indent = Cm(0)`).
* **Отступ после заголовка (Space After):** $12\text{ pt}$ – $15\text{ pt}$ (одна пустая строка до текста).
* **Отступ до заголовка (Space Before):** $0\text{ pt}$.
* **Точка в конце:** **СТРОГО ЗАПРЕЩЕНА**.
* **Пример:** `ГЛАВА 1. ТЕОРЕТИЧЕСКИЕ ОСНОВЫ ИПОТЕЧНОГО КРЕДИТОВАНИЯ`

### 3.2. Заголовки 2-го уровня (Параграфы / Подразделы)
* **Размещение:** Внутри текста (без принудительного разрыва страницы).
* **Гарнитура:** Times New Roman.
* **Кегль:** $14\text{ pt}$.
* **Начертание:** Полужирный (Bold), Строчные с первой прописной.
* **Выравнивание:** С абзацного отступа ($1.25\text{ см}$) или по центру.
* **Отступ До (Space Before):** $12\text{ pt}$.
* **Отступ После (Space After):** $12\text{ pt}$.
* **Точка в конце:** **ЗАПРЕЩЕНА**.
* **Пример:** `1.1 Сущность и экономическое значение ипотечной ставки`

## 4. Сноски (Footnotes Format)

Сноски используются для указания ссылок на источники, пояснений и терминологических примечаний внизу страницы.

* **Шрифт:** Times New Roman.
* **Кегль:** $10\text{ pt}$ (`Pt(10)`).
* **Цвет шрифта:** Черный (`RGBColor(0, 0, 0)`).
* **Межстрочный интервал:** Одинарный ($1.0$ / `line_spacing = 1.0`).
* **Выравнивание:** По ширине (`WD_ALIGN_PARAGRAPH.JUSTIFY`).
* **Абзацный отступ (Красная строка):** $0.5\text{ см}$ или $1.25\text{ см}$ (согласно ГОСТ 7.32-2017 по дефолту $1.25\text{ см}$).
* **Нумерация:** Постраничная (начинается с 1 на каждой странице) или сквозная.
* **Отделительная черта (Separator Line):** Длина $1.5\text{ см}$ ($1.5 \text{ cm} \approx 850\text{ dxa}$), толщина $0.5\text{ pt}$, слева.

### OpenXML & python-docx реализация сносок:
```python
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def add_footnote(paragraph, footnote_text, footnote_id):
    """
    Вставляет маркер сноски в параграф и создает соответствующую сноску в w:footnotes.
    """
    # 1. Вставка надстрочного знака (run) в параграф
    run = paragraph.add_run()
    rPr = OxmlElement('w:rPr')
    rStyle = OxmlElement('w:rStyle')
    rStyle.set(qn('w:val'), 'FootnoteReference')
    rPr.append(rStyle)
    run._r.append(rPr)
    
    footnote_ref = OxmlElement('w:footnoteReference')
    footnote_ref.set(qn('w:id'), str(footnote_id))
    run._r.append(footnote_ref)

    # 2. Настройка стиля абзаца сноски (10pt, 1.0 spacing, justified)
    # В компиляторе используется кастомный Footnote Style
```

## 5. Приложения (Appendix Format)

Приложения оформляются в конце документа после Списка литературы.

* **Размещение:** Каждое приложение начинается **С НОВОЙ СТРАНИЦЫ** (`page_break_before = True`).
* **Заголовок приложения:**
  * **Формат:** `ПРИЛОЖЕНИЕ А`, `ПРИЛОЖЕНИЕ Б` (буквы русского алфавита, за исключением Ё, З, Й, О, Ч, Ъ, Ы, Ь).
  * **Выравнивание:** По правому краю или По центру вверху страницы.
  * **Шрифт:** Times New Roman, $14\text{ pt}$, Полужирный, ПРОПИСНЫЕ БУКВЫ.
  * **Отступ после:** $6\text{ pt}$.
* **Название приложения:**
  * **Размещение:** Строкой ниже под заголовком `ПРИЛОЖЕНИЕ А`.
  * **Выравнивание:** По центру, Полужирный, С прописной буквы.
  * **Отступ после:** $12\text{ pt}$.
* **Нумерация страниц:** Сквозная продолжается через все приложения.
* **Нумерация рисунков/таблиц в приложении:** Своя для каждого приложения, например: `Таблица А.1`, `Рисунок Б.2`.

## 6. Формулы и Математические Выражения (Formulas Format)

Формулы выделяются из текста в отдельную строку (выключные формулы).

* **Выравнивание формулы:** По центру страницы.
* **Нумерация формулы:** По правому краю в круглых скобках, например: `(1.1)` или `(2)`.
* **Шрифт в формуле:** Times New Roman / Cambria Math, $14\text{ pt}$, Курсив (для латинских букв).
* **Отступы До и После:** По $6\text{ pt}$ – $12\text{ pt}$.

### python-docx Реализация с бескаркасной таблицей:
Для точного выравнивания формулы по центру и номера строго по правому краю используется 1-строчная бескаркасная таблица с шириной 100%:
```python
def insert_gost_formula(doc, formula_omml_or_text, formula_num):
    table = doc.add_table(rows=1, cols=2)
    table.autofit = False
    
    # Ширина столбцов: Формула (центр) - 14 см, Номер (право) - 3 см
    table.columns[0].width = Cm(14)
    table.columns[1].width = Cm(3)
    
    # Убираем все границы таблицы
    for cell in table.rows[0].cells:
        tcPr = cell._tc.get_or_add_tcPr()
        tcBorders = OxmlElement('w:tcBorders')
        for border_name in ['top', 'left', 'bottom', 'right']:
            b = OxmlElement(f'w:{border_name}')
            b.set(qn('w:val'), 'none')
            tcBorders.append(b)
        tcPr.append(tcBorders)

    # Ячейка 0: Текст/OMML формулы по центру
    p0 = table.cell(0, 0).paragraphs[0]
    p0.alignment = WD_ALIGN_PARAGRAPH.CENTER
    p0.paragraph_format.first_line_indent = Cm(0)
    p0.add_run(formula_omml_or_text)

    # Ячейка 1: Номер формулы по правому краю
    p1 = table.cell(0, 1).paragraphs[0]
    p1.alignment = WD_ALIGN_PARAGRAPH.RIGHT
    p1.paragraph_format.first_line_indent = Cm(0)
    p1.add_run(f"({formula_num})")
```

## 7. Нумерация Страниц (Page Numbers)

* **Размещение:** Внизу страницы, по центру (Bottom Center).
* **Шрифт:** Times New Roman, $12\text{ pt}$ или $14\text{ pt}$.
* **Сквозная нумерация:** Арабские цифры ($1, 2, 3 \dots$).
* **Особые правила:**
  * Счет начинается с Титульного листа (стр. 1).
  * На Титульном листе номер **НЕ ОТОБРАЖАЕТСЯ** (`different_first_page_header_footer = True`).
  * Номера страниц начинают фактически печататься со страницы 3 (Введение) или страницы 2 (Содержание).

## 8. Таблицы (Tables Format)

* **Шрифт внутри таблицы:** Times New Roman, $12\text{ pt}$ (допускается $10\text{ pt}$ при высокой плотности данных).
* **Межстрочный интервал в таблице:** Одинарный ($1.0$).
* **Выравнивание текста в ячейках:**
  * Шапка (Headers): По центру, полужирный.
  * Текстовые данные: По левому краю.
  * Числовые данные: По правому краю или по центру.
* **Подпись таблицы:**
  * Размещается **НАД** таблицей.
  * Выравнивание: По левому краю с абзацного отступа ($1.25\text{ см}$) или по левому краю.
  * Формат: `Таблица 1.1 — Название таблицы` (без точки в конце).
* **Границы:** Сплошная черная линия $0.5\text{ pt}$.
* **Перенос шапки:** Шапка таблицы должна повторяться на следующей странице при разрыве (`w:tblHeader`).
* **Запрет разрыва строк:** Строки таблицы не должны разрываться между страницами (`w:cantSplit`).

---

## 9. Иллюстрации и Рисунки (Figures Format)

* **Выравнивание рисунка:** По центру (Center).
* **Подпись рисунка:**
  * Размещается **ПОД** рисунком.
  * Выравнивание: По центру (Center).
  * Шрифт: Times New Roman, $12\text{ pt}$ или $14\text{ pt}$.
  * Формат: `Рисунок 1.1 — Название рисунка` (без точки в конце).
* **Отступы:** $6\text{ pt}$ до рисунка, $12\text{ pt}$ после подписи.

---

## 10. Списки (Lists Format)

* **Маркированный список:** В качестве маркера используется тире (`— `) или дефис.
* **Нумерованный список:** `1. `, `2. ` или с круглой скобкой `1) `, `2) `.
* **Отступы списка:**
  * Абзацный отступ первого уровня: $1.25\text{ см}$.
  * Межстрочный интервал: $1.5$.
  * Каждый пункт заканчивается запятой `,` или точкой с запятой `;`, последний пункт — точкой `.`.

---

## 11. Список Литературы (Bibliography Format)

* **Название раздела:** `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ` (Заголовок 1 уровня).
* **Сортировка:** Алфавитный порядок (русскоязычные источники, затем иностранные) или По мере упоминания в тексте.
* **Форматирование:**
  * ГОСТ Р 7.0.100-2018 / ГОСТ 7.1-2003.
  * Шрифт: Times New Roman $14\text{ pt}$, интервал $1.5$.
  * Выравнивание: По ширине.
  * Каждая запись имеет сквозной номер `1. `, `2. `.

## 12. Шаблоны Титульных Листов (Title Page Specifications)

Титульный лист — страница 1 документа (номер скрыт). Настройки полей стандартные (Левое 30 мм, Правое 10 мм, Верх/Низ 20 мм).

### 12.1. Шаблон для Курсовой Работы
1. **Верхний блок (Шапка ВУЗа):**
   * `МИНИСТЕРСТВО НАУКИ И ВЫСШЕГО ОБРАЗОВАНИЯ РОССИЙСКОЙ ФЕДЕРАЦИИ` (TNR 12pt, Полужирный, По центру, ПРОПИСНЫЕ).
   * `ФЕДЕРАЛЬНОЕ ГОСУДАРСТВЕННОЕ БЮДЖЕТНОЕ ОБРАЗОВАТЕЛЬНОЕ УЧРЕЖДЕНИЕ ВЫСШЕГО ОБРАЗОВАНИЯ` (TNR 10pt, По центру, ПРОПИСНЫЕ).
   * `«НАИМЕНОВАНИЕ УНИВЕРСИТЕТА»` (TNR 12pt, Полужирный, По центру, ПРОПИСНЫЕ).
   * `Кафедра [Название кафедры]` (TNR 12pt, По центру, Обычный).
   * *Отступ после шапки:* $36\text{ pt} - 48\text{ pt}$.
2. **Центральный блок (Тип и Тема):**
   * `КУРСОВАЯ РАБОТА` (TNR 16pt, Полужирный, По центру, ПРОПИСНЫЕ).
   * `по дисциплине «[Название дисциплины]»` (TNR 14pt, По центру).
   * `на тему: «[Тема работы]»` (TNR 14pt, Полужирный, По центру).
   * *Отступ после темы:* $48\text{ pt} - 72\text{ pt}$.
3. **Блок авторов и проверивших (Справа):**
   * Выравнивание: По правому краю (или таб-стоп на 9-10 см).
   * `Выполнил(а):`
   * `Студент(ка) [Курс] курса [Группа] группы`
   * `[ФИО Студента]` (TNR 12pt).
   * `Проверил:`
   * `[Ученая степень, должность]`
   * `[ФИО Преподавателя]` (TNR 12pt).
   * *Отступ после блока:* Растяжка до низа страницы.
4. **Нижний блок (Город и Год):**
   * `[Город] — 2026` (TNR 12pt, По центру, В самом низу страницы).

### 12.2. Шаблон для Реферата
* Похож на Курсовую работу, но центральный блок заменяется на:
  * `РЕФЕРАТ` (TNR 16pt, Полужирный, По центру, ПРОПИСНЫЕ).
  * `по дисциплине «[Название дисциплины]»`.
  * `на тему: «[Тема реферата]»`.

### 12.3. Шаблон для ВКР (Дипломная работа)
* Центральный блок:
  * `ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА` (TNR 16pt, Полужирный, По центру, ПРОПИСНЫЕ).
  * `(дипломная работа / бакалаврская работа)` (TNR 12pt, По центру).
  * `на тему: «[Тема ВКР]»` (TNR 14pt, Полужирный, По центру).
* Расширенный блок проверки:
  * `Направление подготовки / Специальность: [Код и название]`.
  * `Допустить к защите: Зав. кафедрой [ФИО], [Дата, подпись]`.
  * `Научный руководитель: [Должность, ФИО]`.
  * `Рецензент: [Должность, ФИО]`.

## 13. Чек-лист Детерминированного Валидатора (OpenXML Checklist)

Компилятор перед сохранением `.docx` проверяет XML элементы:
- [x] Отсутствие пустых абзацев для создания отступов (все отступы заданы параметрами `space_after`/`space_before`).
- [x] Присутствие элемента `w:firstLine w:val="709"` во всех абзацах основного текста.
- [x] Присутствие элементов `w:cantSplit` и `w:tblHeader` во всех таблицах.
- [x] Присутствие динамического поля `PAGE` в нижнем колонтитуле.
- [x] Наличие правильной отделительной черты для сносок (`w:separator`).
- [x] Применение `w:pageBreakBefore` для всех заголовков 1 уровня и Приложений.
