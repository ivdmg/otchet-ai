## PDF: отдельная платная API не нужна

Сохранённый AST → существующий `python-docx` → DOCX → LibreOffice → PDF. Это одна цепочка и общая версия текста. Gotenberg — удобная HTTP-обёртка для собственного контейнера; он не является нейросетью. В [официальной установке](https://gotenberg.dev/docs/getting-started/installation) есть образ только с LibreOffice, а [маршрут конвертации](https://gotenberg.dev/docs/convert-with-libreoffice/convert-to-pdf) принимает office-файлы. Денег за запрос стороннему конвертеру нет; CPU, RAM и сопровождение входят в расходы нашего сервера.

| Подход | Цена/ограничение | Применение |
|---|---|---|
| LibreOffice headless в worker | Нет лицензии за запрос; нужен isolation и отдельный profile на процесс | Самый простой spike, далее сравнить с Gotenberg |
| Свой Gotenberg/LibreOffice | Тот же серверный ресурс, удобный HTTP-контракт | Основная рекомендация при прохождении замеров памяти |
| Chromium/Playwright HTML→PDF | Второй шаблон вёрстки, сложнее совпадение с DOCX | Если продукт откажется от DOCX как исходника |
| Печать браузера | Нет серверной конвертации, пользователь сохраняет вручную | Временный деморежим, не обещать одинаковый итог |
| CloudConvert | Сейчас 10 conversion credits/день, low priority, free для personal/testing/hobby | Только обезличенные тесты с проверкой условий |
| PDF.co и аналоги | Условия/кредиты зависят от операции, trial не постоянная бесплатность | Сейчас не подключать |

Лимит CloudConvert подтверждён на [странице тарифов](https://cloudconvert.com/pricing). Это кредиты, а не гарантия 10 длинных документов и не лимит на каждого нашего пользователя. Надёжного подтверждения обещания «50 PDF-запросов ежедневно бесплатно» в проекте нет.

## Производственная конвертация

Ключ кэша: `ast_hash + template_version + renderer_version + font_pack_version`. Повторное скачивание использует готовый файл и не вызывает LLM. Изменение текста создаёт новую пару артефактов; подписывать URL только на готовые файлы.

В бете один conversion slot; очередь максимум 20 ожидающих render jobs, далее backpressure. Начальный timeout 120 секунд на документ, максимум 2 попытки на временной ошибке; эти настройки подтвердить на 10/30/60 страницах. [Gotenberg](https://gotenberg.dev/docs/configuration) описывает последовательную работу одного LibreOffice instance и собственную очередь, поэтому контейнер с десятью входящими запросами не означает десять параллельных конвертаций.

Конвертер доступен только worker. Non-root, read-only root filesystem где возможно, ограниченный tmp, memory/CPU/PID limits, без host mounts с секретами. Запретить исходящую сеть и внешние ссылки, `file://` и макросы. Проверить конкретную версию образа и ограничения sandbox. По умолчанию конвертировать только сгенерированный нами DOCX; произвольную пользовательскую методичку обрабатывать отдельно в карантине.

Шрифты и лицензии: нельзя автоматически копировать Microsoft Times New Roman в образ без проверки прав. Легально лицензировать нужный шрифт либо согласовать альтернативу с пользователем; метрически близкий шрифт не гарантирует выполнение конкретной методички. Сохранить font pack version. PDF и Word могут переносить строки по-разному: нельзя обещать идеальное совпадение всех версий Word и 100% ГОСТ без проверки.

Приёмка: кириллица извлекается из PDF, нет пустых страниц/обрезки, таблицы/сноски/формулы/титульник корректны, шрифты доступны, page count проверен. Эталонные DOCX открыть в Word и LibreOffice, PDF сравнить визуально. Существующие OpenXML тесты не обнаружат все проблемы пагинации.

## LLM: дешёвая генерация текста

Не смешивать LLM API с PDF API. Основная переменная стоимость — создание текста и повторные попытки. Текущий `LLMClient` ориентирован на OpenAI-compatible chat completions, но возвращает только content и теряет usage. Нужен результат с текстом, usage, model/version, request_id и finish_reason; адаптер конкретного провайдера, а не одна предположительно универсальная схема.

| Кандидат | Почему рассматривать | Условие выбора |
|---|---|---|
| Yandex AI Studio Lite/Flash | Рубли, российский контрагент, недорогой baseline | Договор/регион обработки + собственный тест JSON и русского текста |
| GigaChat API | Российский кандидат и коммерческие тарифы | Проверить коммерческое разрешение именно для статуса продавца |
| Открытая модель у российского inference-провайдера | Возможен лучший баланс цены/качества | Проверить фактический маршрут и место обработки, не только домен посредника |
| Прямой DeepSeek/OpenRouter | Уже близок текущему клиенту, потенциально дёшево | Не включать с ПД без правовой проверки трансграничной передачи |
| Своя LLM на GPU | Контроль, но дорогие ресурсы/эксплуатация | До 1000 зарегистрированных не оправдана без фактической загрузки |

На [официальном тарифе Yandex](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing) Lite указан по 0,20 ₽/1000 входящих и исходящих токенов синхронно, 0,10 ₽ асинхронно; Flash — 0,10 ₽ вход / 0,20 ₽ выход синхронно. Это ориентиры на дату проверки, не зафиксированная коммерческая оферта для нашего аккаунта. Асинхронность нашего Celery сама по себе не даёт асинхронный тариф провайдера.

[GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/tariffs) разделяет физлиц, ИП/юрлиц и условия коммерческого использования. Не переносить бесплатный личный пакет в платный SaaS без разрешения. Текущий model alias DeepSeek также нельзя считать вечным: [официальная документация](https://api-docs.deepseek.com/quick_start/pricing/) показывает актуальные модели и разные условия peak/off-peak.

## Защита бюджета и качества

- Первые 50 пользователей — приглашения, одно trial-задание ограниченного объёма, глобальный stop-loss. Бонус не становится деньгами к выводу; нельзя многократно получать его сменой email.
- План: максимум 2–3 варианта в trial. Основную генерацию выполнять после утверждения плана. На MVP реферат и ограниченная курсовая; длинную ВКР включать после измерения затрат и юридической проверки.
- Разбивать по разделам; хранить успешный шаг до следующего. Передавать короткое summary соседнего раздела, не весь документ каждый раз. AST schema validation, ограничения глубины/числа узлов и длины.
- Один вызов не равен одной работе: на работу могут приходиться 10–30 обращений. Считать все input/output, repair, retries и fallback.
- Стартовый бюджет job 50 ₽, глобальный дневной 300 ₽, beta-недельный 1500 ₽ — предлагаемые ограничения владельца, не тарифы. Перед внешним вызовом атомарно резервировать его максимальную стоимость; несколько воркеров не должны вместе пробить лимит.
- Retry с jitter, Retry-After, ограничением суммарного времени; 401/403 и ошибочный запрос не повторять. Текущий клиент заворачивает network errors в LLMAPIError, а retry ожидает httpx.RequestError: согласовать и проверить фактическую цепочку.
- При таймауте учитывать неопределённый расход. Reserve бюджета может быть консервативнее фактического; reconcile по usage/счёту. Fallback только на заранее разрешённый провайдер и в оставшемся бюджете.
- ФИО, email, группа, преподаватель и реквизиты оплаты не нужны LLM; титульный лист собирать локально. Свободный текст/методичка всё равно могут содержать ПД: маскирование не равно гарантированному обезличиванию.
- Не выдавать выдуманную библиографию за проверенную. На MVP использовать источники пользователя/проверяемый каталог, сохранять provenance. Если проверка отсутствует — пометка и явное ограничение продукта, без обещания гарантированного антиплагиата.

До выбора провайдера: одинаковые 20 обезличенных заданий на 2–3 моделях; метрики валидного AST, русского текста, ссылок, latency p50/p95, стоимости **успешного** документа вместе с repair. Побеждает минимальная стоимость приемлемого результата, а не минимальная цена токена.
