# Зарубежная LLM и бесплатный настоящий прототип

Проверено 01.11.2026 по официальным страницам. Ни один реальный API-ключ/аккаунт владельца не проверен. Здесь выбор для последующей реализации, не отчёт о состоявшемся деплое. Российские модели исключены по предпочтению владельца.

## Выбор

**Для бесплатного личного теста первым проверить Groq Free с доступной большой текстовой моделью. Для первых продаж — прямой DeepSeek Flash после проверки качества, доступа, оплаты и правовых условий.** Adapter уже близок существующему OpenAI-compatible клиенту. Один настроенный provider/model на job; не строить многопровайдерную платформу и не менять модель молча посреди текста.

| Сервис | Подтверждённое предложение | Решение |
|---|---|---|
| Groq, именно Groq, не Grok | Есть Free tier; published free table для `openai/gpt-oss-120b`: 30 RPM, 1000 RPD, 8000 TPM, 200000 TPD | Первый бесплатный smoke test; проверить русский текст/JSON и доступ владельцу |
| OpenRouter `:free` | Free variants: 20 RPM, 50 запросов/день; повышение после покупки $10 кредитов до 1000/день по условиям | Запасной бесплатный вариант при допустимом доступе/маршруте; выбрать конкретную модель |
| Gemini 2.5 Flash-Lite | Free input/output в доступном регионе; paid $0.10 input / $0.40 output за 1 млн токенов | Полезный дешёвый ориентир, но РФ отсутствует в официальном списке регионов; не основной путь для российского владельца |
| Прямой DeepSeek Flash | Paid API; $0.15–0.30 input cache-miss и $0.60–1.20 output за 1 млн, off-peak/peak | Основной кандидат дешёвого paid MVP; гарантированный постоянный free quota не подтверждён |
| xAI Grok | Платные модели в текущей документации; постоянные «10 бесплатных API-вызовов/день» не подтверждены | Не выбирать ради бесплатности; бесплатный чат Grok не равен бесплатной API |

Источник лимитов Groq — [rate limits](https://console.groq.com/docs/rate-limits), наличие free — [billing FAQ](https://console.groq.com/docs/billing-faqs). Лимиты организации в кабинете приоритетны: провайдер может менять доступ моделей. Groq 8K TPM требует небольших глав/запросов, учёта input+output и пауз. На 50K токенов в работе TPD=200K даст теоретически около 4 работ/день без повторов, а не 1000 работ. Один слишком большой запрос может не пройти TPM вообще. Модель с `openai/` в имени здесь — открытая модель, обслуживаемая Groq, не вызов OpenAI API.

OpenRouter: [free models](https://openrouter.ai/collections/free-models), [pricing](https://openrouter.ai/pricing), [limits](https://openrouter.ai/docs/api-reference/limits), [terms](https://openrouter.ai/terms). 50 запросов = общий лимит аккаунта, не на пользователя и не 50 работ. При 10–20 вызовах на работу это 2–5 полных тестов/день без ошибок. Не использовать случайный `openrouter/free` для сравнения качества: фиксировать реально ответившую модель и провайдера. Доступ для российского аккаунта/географии и разрешённые конечные пользователи требуют отдельной проверки, успешный сетевой ответ не заменяет договорную допустимость.

Gemini: [pricing](https://ai.google.dev/gemini-api/docs/pricing), [regions](https://ai.google.dev/gemini-api/docs/available-regions). Free tier может использовать содержание для улучшения продуктов; квота зависит от модели/проекта, смотреть кабинет, не выдавать лимит Google Search grounding за квоту генерации. Перенос сервера за рубеж не отменяет ограничений пользователя/договора. Не планировать обход ограничений и не обещать оплату российской картой.

DeepSeek: [официальные цены](https://api-docs.deepseek.com/quick_start/pricing/). Текущий alias `deepseek-flash`, версия на странице `DeepSeek-V4.1-Flash-1017`; старое `deepseek-chat` не фиксировать как вечный выбор. Для 20K input + 30K output расчёт $0.021–0.042 до retry; +30% ≈$0.027–0.055. При **условном**, не валютном курсе 100 ₽/$ — 2,7–5,5 ₽/работа. Фактические token counts, курс, thinking и способ пополнения могут изменить стоимость; консервативный резерв 10–25 ₽/работа пока сохраняем. Thinking выключить/ограничить документированным способом для выбранной модели, иначе проверить его стоимость отдельно.

xAI: [models/pricing](https://docs.x.ai/developers/models). [Объявление free credits](https://x.ai/news/api) относилось к beta до конца 2024 года; не принимать его за действующую вечную акцию. Промокредит в конкретном кабинете возможен, но в бюджет не заложен.

## Настоящий бесплатный тест без переписывания продукта

**Вариант A, рекомендуемый первым:** весь сервис локально на компьютере владельца + настоящий Groq API. Это 0 ₽ за hosting, сохраняет PostgreSQL/worker и файлы между запусками. Проверяется реальная генерация и DOCX, а не заранее зашитый ответ. Это самостоятельный полноценный шаг до облачного теста.

**Вариант B, ссылка для владельца:** один Render Free Python Web Service, который отдаёт сборку Vite и FastAPI на одном origin, плюс временная Render Free PostgreSQL. Один ограниченный background executor работает внутри web-процесса, берёт jobs из БД, возобновляет после restart; отдельный paid Background Worker не подключаем. Запрос запуска быстро возвращает job ID, UI polls status. На слабом сервере только одна генерация, без PDF/LibreOffice.

В прототипе DOCX сохранять в маленькую BYTEA-запись в тестовой БД с лимитом, например 20 документов по 5 МБ; местный `/tmp` — только staging. Это простой временный storage adapter, а не production-решение. После миграции на VPS — закрытый persistent disk. AST/шаги в PostgreSQL позволяют пересобрать DOCX. Временные файлы/SQLite Render не считать сохранёнными.

[Render Free](https://render.com/docs/free) указывает sleep после 15 минут без входящего трафика, ephemeral filesystem, free DB на 30 дней и 750 instance hours/workspace/month. Cold start может занять около минуты. Внутренний executor не является гарантированно постоянным worker: при сне/рестарте запуск продолжится после пробуждения и восстановления lease. Не обещать фоновой генерации непрерывную работу после закрытия вкладки на free-стенде. Не добавлять искусственный ping для обхода sleep; показать ограничение владельцу.

Прототип закрыт владельцу паролем/токеном, без публичной регистрации, реальных email/ФИО одногруппников и настоящих оплат. Использовать собственные обезличенные учебные темы; ЮKassa sandbox для денег и тестовые приглашённые аккаунты для рефералки. API и сгенерированный текст настоящие; sandbox-платежи маркированы явно, не выдаются за денежную выручку. Не подключать почтовые рассылки: можно проверить auth через закрытый test mail sink/ручное извлечение одноразового токена только в dev-режиме.

До deploy проверить условия/доступность Render для аккаунта; не утверждать, что карта и зарубежная регистрация никогда не потребуются. Вписать дату истечения DB и экспортировать нужные результаты заранее. Если free provider/hosting недоступен владельцу, использовать локальный вариант; автоматического переключения на платный тариф нет.

## Почему Vercel не основной backend этого теста

[Hobby](https://vercel.com/docs/plans/hobby) ограничен personal/non-commercial use; подготовку коммерческого сервиса нельзя автоматически объявлять допустимой только из-за закрытой ссылки. [Functions](https://vercel.com/docs/functions/limitations) имеют ограниченное время выполнения и не заменяют наш постоянно работающий процесс/диск. Vercel годится для допустимого условиями frontend preview; для настоящего приложения добавит отдельный backend, CORS и хранение. Поэтому сначала один Render origin либо полностью локально. Платные продажи — прежний VPS в РФ.

## Переход к продажам

1. Получить рабочий допустимый ключ, записать фактические лимиты и проверить 1 план/раздел/DOCX локально.
2. Пройти 3–5 реальных полных тестов, включая 429, restart и восстановление прогресса, на закрытом free-стенде. Сравнить качество 5–10 тем на Groq и небольшом paid DeepSeek, если владелец решит пополнить.
3. Если качество принято — VPS в РФ, постоянная БД/диск, реальные auth/email, backup, ЮKassa и бонусный журнал. Новые paid jobs не запускать на исчерпанном free quota.
4. До передачи клиентских данных зарубежной LLM проверить трансграничную обработку, договор/получателей/уведомления и допустимость доступа. ФИО титульника собирать локально и не отправлять LLM; свободный текст тоже проверять. Закрытый обезличенный тест не является разрешением переносить туда production ПД.

Дополнительная полезная функция без отдельной API: «Паспорт оформления» — рядом с DOCX показать фактически проверенные поля/шрифт/интервал, наличие разделов и доступные проверки источников. Не выдавать наличие списка литературы за проверку реальности источников, и не писать «ГОСТ пройден» по одному промпту. Опционально после основного сценария, без расширения первого теста.
