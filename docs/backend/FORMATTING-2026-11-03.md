## Word/PDF

- Новый renderer app/prototype/layout.py: A4, поля 30/15/20/20 мм, основной текст Times New Roman 14, чёрный, 1.5 интервала, отступ 1.25 см, выравнивание по ширине. Заголовки/титул/подписи имеют собственное предусмотренное выравнивание.
- Внешний вид заголовков отделён от Word outline: custom paragraph styles основаны на Normal с outlineLvl=9. Треугольники сворачивания не нужны; встроенные Heading 1/2 не используются в готовых абзацах.
- Содержание на отдельной странице: главы, параграфы, введение, заключение, источники; правый табулятор с точечным лидером, номера через PAGEREF на закладки. Word обновляет поля, перепагинирует, сохраняет DOCX и экспортирует PDF. Заголовочные outline-стили для этого не нужны.
- Титул построен по композиции примера: министерство/организация/кафедра сверху, вид работы, дисциплина и тема в центре, автор и руководитель справа, город/год внизу. В образце были поля 12.7 мм и многочисленные пустые абзацы; они не копируются. Сам образец не является шаблоном с зашитыми чужими ФИО.
- Профиль фиксируется при подтверждении плана в отдельном Document.title_data. Миграция studio_title_layout применена. Используются university, faculty, department, specialty, city, course, group, studentName, supervisor и отображаемое имя. Эти поля не включаются в settings/prompts LLM. Снимок исключён из metadata backup, очищается при истечении выдачи. Изменение профиля после approval не меняет уже утверждённый заказ.
- Титульник учитывается в объёме, но номер на нём не печатается; сквозные номера далее снизу по центру. Город/год титульника закреплены в первом нижнем колонтитуле без пустых абзацев.
- Введение, главы, заключение и источники начинаются с новой страницы через page_break_before. Нет набивки пустыми строками. Источники не делят последнюю страницу с заключением.
- Unicode-тире и математический минус нормализуются в обычный ASCII-дефис по прямому требованию владельца, включая текст, заголовки, таблицы и подписи. Это типографическое правило, не гарантия прохождения антиплагиата или AI-детектора.
- Дублирующий отдельный заголовок внутри ответа модели удаляется. Источники выводятся отдельными нумерованными абзацами; их достоверность не считается проверенной.

## Строгий объём

Минимум — 7 страниц при двух главах и 8 при трёх. Пять фиксированных страниц: титул, содержание, введение, заключение, источники. Остальной объём распределяется между главами и параграфами; задания/страницы/целевые слова фиксируются в job.units. Бюджет учитывает заголовки и русские длинные слова.

Слишком длинный фрагмент не обрезается: он отклоняется до checkpoint и повторно запрашивается с меньшей целью, максимум три попытки в существующем токенном бюджете. Reported tokens учитываются и для ответа, требующего исправления, вместо потери известного usage. При окончательном расхождении страниц PDF — page_count_mismatch, terminal failure и штатный возврат/освобождение резерва. Не начисляются награды за непроверенную выдачу. Частичный Word при таком отказе недоступен через delivery endpoint.

Это не автоматическая научная рецензия: совпадение числа страниц не доказывает содержательность, достоверность библиографии или соответствие отдельной методичке вуза.

## Интерфейс

- Во время ожидания сразу показывается основной outline-grid, с реальными числом глав из параметров, скелетонами внутри полей и компактной Thinking Orb справа. Нет отдельной полноэкранной плановой загрузки. Ответ плана приходит атомарно; фиктивного поочерёдного получения глав нет.
- Статус aria-busy, доступные сообщения ожидания, блокировка редактирования во время запроса, reduced-motion для скелетонов. После ответа заполняются те же карточки.
- Stepper исправлен с устаревшей сетки на 4 колонки на 3, центрирован, активные/пройденные кружки используют цвет кнопок. Доступны все достигнутые шаги, недостигнутые disabled. Фоновый polling не возвращает пользователя насильно на генерацию после каждого ответа.
- При возврате после заказа задача и план доступны только для просмотра, дублирующий checkout не запускается. Активную генерацию можно вновь открыть из библиотеки; completed/expired metadata не становятся архивом готового текста.
- В браузере проверены загрузка и готовый план в одном макете, возврат План → Задача → План, недоступность третьего шага до заказа, светлая/тёмная тема. После удаления/добавления глав счётчик параметров синхронизируется; невозможные 3 главы на 7 страницах запрещены.

## Таблицы, рисунки, формулы: предложение следующего этапа

Таблицы отдельно отложены владельцем. Новых переключателей с неподключёнными обработчиками и изменения цены сейчас нет.

Предлагаемый UX: на первом шаге один выключенный по умолчанию переключатель «Визуальные материалы (+20 ₽ за работу)», а на плане — привязанные к параграфам действия «Добавить таблицу» / «Прикрепить рисунок». Сначала подтверждается смысловая структура, затем пользователь видит предполагаемые места объектов до оплаты. Сервер хранит тип/место/подпись/источник и считает надбавку один раз, включая её в approval_hash. Объекты занимают часть заказанных страниц, не добавляются сверх оплаченного объёма.

- Таблица: подпись «Таблица N - Название» сверху **слева без отступа** (это требование ГОСТ 7.32, а не справа); повторяемая шапка, запрет разрыва строки, ссылка в тексте. Текущий renderer нормализует тире и передаёт номер, выравнивает подпись без абзацного отступа. Полная приёмка многостраничных таблиц отложена.
- Рисунок: изображение/график по центру, подпись «Рисунок N - Название» снизу по центру, ссылка в тексте. Начать с загрузки владельцем и диаграмм по структурированным данным; не вставлять случайные найденные изображения. Проверять тип/размер/пиксели, удалять EXIF, хранить временно с owner-scoped доступом.
- Формула: отдельная строка по центру, номер справа в круглых скобках, расшифровка символов ниже; использовать математическое представление, а не растровый скриншот.
- Листинг: моноширинный текст, сохранённые переносы, нумерация и подпись. Расположение подписи по методичке; требование владельца справа сверху можно сохранить для листингов отдельным правилом, не выдавая его за универсальное правило таблиц ГОСТ.
