## Рабочая конфигурация

```dotenv
AI_PROVIDER=openrouter
OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
OPENROUTER_REASONING_EFFORT=none
```

OPENROUTER_API_KEY берётся из .env, не из frontend. Модель доступна бесплатно на момент проверки. Платного fallback нет.

Начальный openrouter/free принимал минимальный запрос, но полный план не прошёл валидацию ответа. Закреплена конкретная бесплатная модель вместо случайного маршрутизатора.
