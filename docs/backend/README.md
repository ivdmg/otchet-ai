## Рекомендация

Сохранить React/Vite, FastAPI, SQLAlchemy, PostgreSQL, Celery и python-docx. Развернуть модульный монолит на одном VPS **в российском дата-центре**, добавить приватный S3 в РФ, конвертировать DOCX в PDF собственным LibreOffice/Gotenberg. На старте один LLM-воркер и один конвертер; масштабировать по очереди и измерениям. Kubernetes, микросервисы, отдельная векторная БД и платная PDF API сейчас не нужны.

Вход: email + пароль, подтверждение email, восстановление, серверные cookie-сессии. Работы и версии AST сохранять в PostgreSQL; PDF/DOCX и загрузки — в S3; Redis использовать для доставки задач, а не как единственное место хранения прогресса. Платежи: ЮKassa с размещённой страницей оплаты, СБП и картами, без автопродлений на MVP. Выбор окончателен после подтверждения провайдером категории бизнеса и статуса продавца.

Сначала бесплатная закрытая бета по приглашениям, затем платный пилот после выполнения юридических и технических условий. Бесплатность для пользователя оплачивает владелец: LLM, VPS и почта могут стоить денег с первого дня.

## Условия запуска

**Закрытая бета:** защищены все каналы доступа, реальные сохранения, резервное копирование и восстановление, лимит расходов и приглашения; определён оператор данных, опубликована политика, выполнены применимые уведомления. Бесплатная бета не освобождает от требований к персональным данным.

**Платный пилот:** дополнительно оформлен продавец, подтверждён эквайринг, работают чеки и возвраты, опубликована проверенная оферта, проверено позиционирование. Ошибки генерации не теряют деньги клиента.

**Рост:** число зарегистрированных пользователей само по себе не является основанием для миграции. Основания — очередь, память, CPU, время ответа БД, стоимость успешного результата и восстановление после аварии.
