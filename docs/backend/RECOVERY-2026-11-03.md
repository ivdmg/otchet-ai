# Восстановление генерации и дополнительные материалы

## Реальная доступность AI

В локальной истории подтверждены отказы OpenRouter 403: при подготовке плана и библиографии. Историческое тело ответа не сохранялось, поэтому точную причину старого отказа установить нельзя. Проверка метаданных текущего ключа вернула 200; один контрольный запрос плана принят, 378 токенов, две главы. Полная живая работа в этом прогоне не заказывалась. При будущих отказах сохраняются только HTTP-статус и безопасная категория причины, без ключей и сырого ответа.

## Контракт восстановления

| Ситуация | Поведение |
| --- | --- |
| 403, 401, недостаток баланса, дневная квота при генерации текста | Пауза, сохранённые разделы, явное продолжение того же заказа без новой оплаты либо отмена |
| 429 по частоте, timeout, 5xx, некорректный ответ | Ограниченные автоматические повторы, затем пауза; учитывается время следующей попытки |
| Потеря связи браузера | Проверка статуса; не создаётся новый оплаченный заказ вслепую |
| Зависший worker без обновлений более 180 секунд и без действующей аренды | Проверка статуса, возобновление с новым fencing token или отмена |
| Ошибка плана | Понятная карточка с повтором и переходом к параметрам |
| Ошибка бесплатной перегенерации | Сохраняется предыдущий план; его можно утвердить |
| Повторная неудача | Не более двух ручных продолжений одного запуска; затем отмена/сохранённый план |
| Отмена | Подтверждение в модалке; старый worker не может завершить отменённый заказ |
| Пауза 24 часа | Автоматическая отмена, возврат или освобождение бонусного резерва |
| Истёкшая выдача | Нет скачивания, нет бесконечного индикатора готовности; можно создать новый черновик |
| Уже возвращенная оплата | Старый job не возобновляется; план копируется в новый неоплаченный черновик |
| Несовпадение количества страниц | Работа не выдаётся как готовая, применяется возврат/освобождение резерва |

Возобновление сохраняет `order_id`, checkpoints, консервативно учтённый расход токенов и предел бюджета. Отмена и освобождение бонусов идемпотентны. Реальные возвраты проходят существующую сверку платежного провайдера; локальный mock не списывает деньги. Ошибка после отмены не меняет терминальное состояние. Бэкап приостановленного задания не разрешает автоматически запускать его без восстановленного содержимого.

## План и интерфейс

Единый лейаут загрузки/готового плана. Орб в шапке занимает постоянный слот 42×42 px, справа остаётся статичная иконка. В строках глав, параграфов, введения, заключения, источников и добавления главы отображаются спиннеры; при ошибке они прекращаются. При подготовке доступна отмена с подтверждением. Одна дополнительная бесплатная перегенерация хранится на сервере и не сбрасывается перезагрузкой страницы. Ручное редактирование остаётся бесплатным.

Справа расположены тип, объём, главы, форматы Word/PDF и итог до оплаты. Переключатель материалов доступен на первом и втором этапах. Его изменение после утверждения аннулирует старый approval; после заказа настройка заблокирована.

## Материалы

Надбавка 10% рассчитывается сервером в копейках: реферат 199 → 218,90 ₽, курсовая 490 → 539 ₽, ВКР 1390 → 1529 ₽. Дополнительные материалы входят в заказанный объём. Один компактный табличный блок обязателен, простая линейная формула и листинг добавляются при уместности. Для небольшого объёма количество блоков ограничено свободными страницами. Расположение и бюджеты слов замораживаются в заказе, не более одного материала на страницу. Рендерятся настоящие таблицы Word, формулы OMML с номером и пояснением, листинги с подписью и Courier New. Код только отображается и никогда не выполняется.

Содержимое валидируется до checkpoint: размеры таблиц/кода, согласованность столбцов, недопустимые XML-символы, разрешённый тип материала. PDF проверяется по реальному числу страниц и тексту, включая таблицы и математические символы. Преобразование математического курсива Word учитывается Unicode-нормализацией при сравнении с PDF.

## Проверка

Автотесты используют отдельную PostgreSQL-базу `gostdoc_proto_test` и явные AI doubles, без сетевых вызовов модели. Полный путь после 403 до DOCX/PDF проверяется настоящим конвертером Word, 7 страниц, одна оплата и одно начисление. Материалы проверены на настоящем Word/PDF, ровно 10 страниц. В браузере проверены загрузка, отказ, явный повтор, подтверждение отмены, сохранение параметров и пересчёт цены. Временный UI-пример удалён; исходный черновик и аккаунт сохранены. Проверены светлая/тёмная темы и ширина 390 px без горизонтального переполнения.

Команда актуального набора:

```powershell
venv/Scripts/python.exe -m pytest tests_prototype/test_recovery.py tests_prototype/test_materials.py tests_prototype/test_studio_v2.py tests_prototype/test_layout.py tests_prototype/test_current_pipeline.py tests_prototype/test_providers.py tests_prototype/test_ai_budget.py -q
npm.cmd run build
```

Результат финального набора: **56 passed**, сборка frontend и compileall прошли. Точные значения текущих ключей не найдены в доступных Git файлах и dist. Миграция `studio_recovery` применена; локальные API/worker перезапущены, Vite доступен на 5173.

Это целевая проверка текущего Studio-контракта, а не заявление о прохождении всех устаревших тестов репозитория. Бесплатный внешний провайдер всё ещё может отказать; теперь отказ имеет завершённый пользовательский сценарий вместо бесконечной загрузки. Production, настоящая оплата и автоматическое переключение на платную модель не включались.
