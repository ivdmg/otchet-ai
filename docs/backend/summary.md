# MVP до 50 пользователей: актуальная краткая сводка

Обновлено 01.11.2026: **рефералка и бонусный баланс обязательны**, российские LLM исключены. Этот файл и [Tasks](../../Tasks/README.md) приоритетнее прежних подробных планов. Детали: [рефералка и прогресс](10-referrals-and-progress.md), [зарубежные API и бесплатный тест](11-foreign-api-and-free-prototype.md).

## Сценарий пользователя

Лендинг → форма с ценой → вход → настоящий AI-план → ручные правки/утверждение → выбор **рубли или реферальные кредиты** → настоящая генерация с этапами → DOCX в «Моих работах».

Одна покупка = одна работа. Никаких платных пополнений кредитов и смешанной оплаты. Недостаточно бонусов — можно оплатить рублями. Реальный баланс/история доступны в аккаунте. Перегенерацию абзацев, PDF, методички, подписки и масштабирование пока откладываем. Полный результат сохраняется на 90 дней.

## Рефералка: пять покупателей дают стандартную работу

1 кредит покрывает 1 ₽ цены услуги; кредиты нельзя купить, передать или вывести. Они начисляются только за рефералку, не за регистрацию/клики. Пользователь делится личной ссылкой. Новый друг привязывается при регистрации; один пригласивший, один уровень.

За первую успешно завершённую и оплаченную рублями работу друга начисляем **20% фактически оплаченной суммы, максимум 1/5 цены стандартной работы**. Пример тарифа: стандартная работа 300 ₽ → награда 60 кредитов за друга, купившего на 300 ₽ или больше → пять разных покупателей = 300 кредитов. Дешёвые покупки дают меньше; повторные и бонусные заказы не дают наград. Цена 300 ₽ — пример, окончательный тариф ещё выбрать.

Награда сначала ожидает 14 дней, затем доступна при отсутствии возврата/спора. При возврате отменяется/уменьшается; уже потраченный бонус создаёт только внутренний бонусный долг, погашаемый будущими наградами. Деньги с пригласившего не требуем, законный возврат друга не блокируем. В UI видны pending/available, история и сколько осталось до работы; чужие темы/работы не показываем.

Кредитный заказ резервирует бонусы перед job, списывает после готового DOCX, возвращает резерв при технической ошибке. Рублёвый заказ после окончательного технического сбоя получает полный денежный refund с реальным статусом и поддержкой, если автоматический возврат не прошёл. Двойные клики/webhook не создают лишних списаний/наград.

## Генерация и настоящий прогресс

Нейросеть работает через внешнюю API. Она создаёт план и структурированный текст (при необходимости по разделам), а существующий python-docx задаёт отступы, стили и таблицы. Покупать отдельную DOCX/PDF API или GPU не нужно.

Progress bar считает **завершённые и сохранённые шаги**: введение 5%, разделы 75%, заключение 5%, источники 5%, валидация 5%, готовый DOCX 5%. Например, «Раздел 3 из 8». Таймер не прибавляет проценты. При ожидании AI/429 показываем ожидание/повтор; 100% только с проверенным файлом. После reload прогресс восстанавливается из БД. Процент шагов не равен проценту времени: пока нет замеров, показываем оставшиеся этапы, а не выдуманные секунды.

## Как бесплатно проверить настоящую работу

**Сначала локальный сервис + Groq Free, затем закрытая ссылка на Render Free**, если аккаунт/география допускаются. Настоящие запросы и настоящий DOCX, без публичных клиентских данных и боевых денег. Рефералка/оплаты проверяются тестовыми аккаунтами и ЮKassa sandbox; это не мок генерации.

[Groq Free](https://console.groq.com/docs/rate-limits) для gpt-oss-120b сейчас публикует 1000 запросов/день, но также 8K токенов/минуту и 200K/день: длинные работы требуют разбивки и пауз. Точные условия/доступ — по кабинету владельца. [OpenRouter free](https://openrouter.ai/collections/free-models) — запасной вариант с 50 запросами/день; ограничения региона/модели проверить отдельно. Это лимиты API на аккаунт, не на каждого нашего пользователя.

[Render](https://render.com/docs/free): один бесплатный Python web service со статикой Vite, временная PostgreSQL, executor внутри процесса. DOCX временно сохраняется небольшим BYTEA в БД: локальный диск пропадает при sleep/restart. Сервис засыпает, free DB истекает через 30 дней. Это личный тест, а не бесплатный production. Если недоступно — локальный вариант. Vercel не основной выбор: Hobby personal/non-commercial, функции не заменяют постоянный worker/диск.

## Какую API брать за деньги

**Основной кандидат — прямой DeepSeek Flash** после теста русского текста/JSON/источников и проверки доступности/пополнения. [Официальная цена](https://api-docs.deepseek.com/quick_start/pricing/) даёт примерно $0.021–0.042 за условные 20K входных + 30K выходных токенов до повторов. Уверенный резерв пока 10–25 ₽ на работу, заменить реальным замером.

Gemini Flash-Lite дёшев и имеет free tier, но РФ отсутствует в [официальных регионах](https://ai.google.dev/gemini-api/docs/available-regions); не обещаем его российскому аккаунту. Для Grok xAI постоянный бесплатный API-лимит не подтверждён. Бесплатный чат не означает бесплатную API. Качество любой модели нужно проверить: гарантировать антиплагиат, AI-детектор и принятие преподавателем нельзя.

## После личного теста

Один VPS в РФ: Vite, FastAPI, PostgreSQL, один worker, файлы на закрытом постоянном диске, внешний backup. S3 для пользовательских работ/Redis/Kubernetes не требуются. Добавляются только небольшой бонусный журнал и реферальные записи, не сложная платёжная платформа.

На 50 обычных генераций прежний ориентир **1800–2800 ₽/месяц** для VPS/AI/мелких технических расходов остаётся плановым. Реферальные работы тоже расходуют AI: если есть 50 квалифицированных денежных покупок, максимум около 10 стандартных наградных работ добавляют примерно 100–250 ₽ при принятой себестоимости. Это обязательство может быть погашено позже; 50 пользователей не равно 50 заказам. В 3000 ₽ технически целимся, 1000 ₽ — слишком тесно. Реклама, домен разовым платежом, налоги, комиссии и возможная платная фискализация отдельно.

Не экономим на HTTPS, паролях/сессиях, owner checks, backup, server-side проверке оплаты и защите от повторов. До продаж — допустимый статус продавца/чеки/оферта/ПД и условия бонусной программы. До передачи реальных данных зарубежной LLM — отдельная проверка трансграничной обработки и правил провайдера. Ограничения рекламы аттестационных работ сохраняются, в том числе для реферальных рекламных материалов; подробности в [правовом разделе](08-russian-legal-launch.md).

Ближайшая утверждённая цель — реализовать настоящий личный прототип. [План исполнения](../../Tasks/EXECUTION-PLAN.md) и [промпты backend/frontend](../../Tasks/README.md) задают автономную работу по фазам и отметки в самих задачах. Сначала backend и передача фактического API, затем frontend и браузерный E2E. ЮKassa sandbox, реальные AI-текст/DOCX и сохранение; локальный полный сценарий достаточен до покупки VPS.
