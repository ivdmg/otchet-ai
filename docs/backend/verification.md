## Тесты текущего приложения

Команда из корня:

```powershell
.\venv\Scripts\python.exe -m pytest -q --disable-warnings --maxfail=3
```

Результат: **126 passed, 1 failed, 1 warning**, 33,05 секунды. Неуспешный тест:

`tests/test_zod_schema.py::test_zod_schema_file_exists_and_valid`

Причина: тест ищет `frontend/src/schemas/docAstSchema.ts`, в текущем проекте файл находится в `src/schemas/docAstSchema.ts`. Исходники не исправлялись: это часть BE-001. Успешные тесты преимущественно используют SQLite/mocks и не подтверждают production платежи, PostgreSQL locks, сетевую изоляцию или capacity.
